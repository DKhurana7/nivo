# Working on Nivo

Read `CODEBASE_REFERENCE.md` before changing the application. Update it when architecture, behaviour, limitations or commands change. Read `PLAN.md` for the design brief and user steering.

Preserve existing sibling projects. Keep cost and selling prices distinct, unpriced items explicit, source evidence traceable and provider availability honest. Never simulate successful real calls or live quotations. Honour the user's visual restrictions and responsive/keyboard/reduced-motion behaviour.

Run meaningful domain tests and browser checks for changes to costing, workbook handling, persistence and workflows. Inspect desktop and phone screenshots for UI changes. Do not add external messaging, purchases, public deployments or provider credentials without applicable authorization.
